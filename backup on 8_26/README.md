# FinCalcPro

FinCalc Pro - Professional Financial Calculator Website with Live NSE/BSE/Gold Data.

## Features
- Home Loan EMI Calculator with Amortization Schedule
- SIP & Investment Return Calculator
- Live Market Indices Ticker (NSE, BSE, Bank Nifty, Nifty IT)
- Real-time Gold & Silver Rates (24K, 22K, Silver)
- Live WebSocket Updates (`/ws`)
- Admin Panel for manual data overrides (`/admin`)

## Quick Start
```bash
npm install
npm dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
